# 주차별 진척 기록

매 주차 파일 하나(`week-NN.md`)를 작성합니다. Claude와 Codex 모두 작업 전에 최신 주차 파일과 `../07_project_handoff.md`를 읽고, 작업 후 해당 주차 파일에 기록합니다.

## 작성 규칙

- **구현 완료**와 **검증 완료**를 구분합니다. 검증은 어떤 명령이나 테스트로 확인했는지 적습니다.
- 작업자(사람, Claude, Codex)를 적습니다.
- 설계 결정이 바뀌면 "결정 변경"에 기록하고 해당 설계 문서(00~08)도 고칩니다.
- 설계 가설과 실제 결과를 섞지 않습니다.

## 템플릿

```md
# N주차 (YYYY-MM-DD ~ YYYY-MM-DD)

## 목표
(05_roadmap.md의 해당 주차 목표)

| 항목 | 작업자 | 상태(구현/검증) | 검증 방법 |
|---|---|---|---|

## 결정 변경
- (무엇을, 왜 바꿨는지, 수정한 문서)

## 문제와 해결
- 

## 미완료 및 다음 주 이월
- 

## 다음 작업
1. 
```
